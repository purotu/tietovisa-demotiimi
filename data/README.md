# Tiedostot tietovarastona

`esimerkkikysymykset.csv` sisältää viisi tietovisakysymystä UTF-8-muodossa.
Erotin on puolipiste (`;`). Ensimmäinen rivi sisältää sarakeotsikot.
`oikea` tarkoittaa vastausvaihtoehdon numeroa 1–4.

Säilyttäkää sovelluksen tarvitsemat lähtötiedot versionhallinnassa.
Korvatkaa esimerkkikysymykset oman projektin aineistolla tarvittaessa.

Tallentakaa ajon aikana syntyvät tulokset kansioon `data/output/`.
Sen sisältö ohitetaan versionhallinnassa lukuun ottamatta `.gitkeep`-tiedostoa,
joka säilyttää muuten tyhjän kansion mukana. Ohjelman on osattava luoda puuttuva
tulostiedosto; ensimmäisellä ajolla sitä ei vielä ole.
